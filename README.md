# ROS2-Learning

Personal ROS 2 learning workspace with C++ and Python examples, robot descriptions, control and hardware experiments, Gazebo simulation, and MoveIt configurations.

## Environment

- ROS 2 Humble
- Ubuntu 22.04
- `colcon` and `rosdep`

Install [ROS 2 Humble](https://docs.ros.org/en/humble/Installation/Ubuntu-Install-Debians.html) before building this workspace. Some packages also use MoveIt, Gazebo, `ros2_control`, and the Dynamixel SDK; `rosdep` installs dependencies declared by their package manifests.

## Workspace structure

The repository root is the `ros2_ws/` colcon workspace. After a build, it looks like this:

```text
ros2_ws/                  # repository and workspace root
├── README.md
├── .gitignore
├── src/                 # ROS 2 packages tracked by Git
├── build/               # generated by colcon
├── install/             # generated by colcon
└── log/                 # generated by colcon
```

`build/`, `install/`, and `log/` are created automatically by `colcon build` and are excluded from Git. A fresh clone contains `src/`, but these generated directories appear only after the build. Run `colcon build` from **`ros2_ws/`**, one level above `src/`.

## Packages

The `src/` directory contains 15 packages:

- Basic nodes and actions: `my_cpp_pkg`, `my_py_pkg`, `actions_cpp`, `actions_py`, `my_robot_interfaces`, `turtlesim_catch_them_all`
- Robot models and launch files: `my_robot_description`, `my_robot_bringup`
- Controllers and hardware: `my_robot_controllers`, `my_robot_hardware`, `dxl_test`
- Motion planning and commanders: `my_robot_moveit_config`, `my_combined_robot_moveit_config`, `my_robot_commander_cpp`, `my_robot_commander_py`

## Clone and build

Install the build and dependency tools if they are not already available:

```bash
sudo apt update
sudo apt install python3-colcon-common-extensions python3-rosdep
```

If this is the first time using `rosdep` on your machine, initialize it once with `sudo rosdep init`. Then clone the repository into a directory named `ros2_ws`:

```bash
cd ~
git clone https://github.com/Sun-Moon-1314/ROS2-Learning.git ros2_ws
cd ros2_ws
```

With your current directory at the workspace root (`ros2_ws/`), source ROS 2, install the declared dependencies, build, and source the resulting workspace:

```bash
source /opt/ros/humble/setup.bash
rosdep update
rosdep install --from-paths src --ignore-src -r -y
colcon build --symlink-install
source install/setup.bash
```

For a later terminal session, run `source /opt/ros/humble/setup.bash` followed by `source ~/ros2_ws/install/setup.bash` before using these packages. To build a single package, run `colcon build --packages-select <package_name>` from `ros2_ws/`.

The Gazebo world at `src/my_robot_bringup/worlds/test_world.sdf` references models and meshes at local absolute paths. Update those paths or provide the assets locally before using that world on another computer.
